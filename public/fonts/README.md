# Noto Sans SC for PDF text extraction

`NotoSansSC-VF.ttf` is the open-source Noto Sans SC variable TrueType font used
for PaperTrip's searchable PDF text layer. Noto Sans CJK and Adobe Source Han
Sans share the same upstream CJK typeface work.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
